# fiction-prose-jp

AIに日本語の小説・物語本文を書かせる、または推敲させるときの執筆規範スキルです。Claude CodeとCodexの双方で使えます。

句点過多や同じ長さの短文が続く「AIくささ」だけでなく、持ち物・時刻・距離・身体状態・人物が知っていることの整合まで確認します。文章の表面を整えるだけでなく、場面が成立しているかを点検するためのスキルです。

## どんな問題を扱うか

AIに小説を書かせると、次のような問題が起こりがちです。

- 句点で細かく切った短文が等間隔に並び、文章がメトロノームのようになる
- 「まさに」「あまりにも」のような空虚な強調語や、感情のまとめ直しが増える
- 視点人物が知らないはずの事実や他人の本心を、地の文で断定してしまう
- 前の場面で手放した物が次の場面で手元に戻るなど、場面の状態が引き継がれない
- 観察できる事実から、人物の判断や一般論へ根拠なく飛躍する
- 安価な代替手段があるのに、高価・希少な資源を都合よく使ってしまう

このスキルは、これらを感覚的な読み返しだけに任せず、生成時の原理と執筆後の点検手順に分けて扱います。

## 規範の核

### 文長の波と、声のある短文

平時の観察や説明は、因果や知覚を一文の中でつなぎます。短文は、山場・転回・宣告など、語り手や人物の声が乗る決め所に限って使います。

「杉の葉ずれ。遠い沢。」のように無人の観察を刻むのではなく、誰の声や判断が乗っている文なのかを確認します。作品固有の文体カルテがある場合は、そのカルテを優先します。

### 判断文の三点照合

観察を越える判断・推測・診断には、次の3点を確認します。

1. **根拠** — 何を見て、何を聞いて、その判断に至ったのか
2. **知識経路** — 視点人物は、その前提をいつ、どう知ったのか
3. **射程** — その観察から、どこまでの範囲を断定できるのか

1つでも欠ける断定は、観察だけを残すか、「かもしれない」のように射程を狭めます。

### 場面の整合

書き出す前に、次の5行を確認します。

1. 前話の締めの一行
2. 時刻と場所
3. 持ち物と残数の増減
4. この話で出す数
5. 視点人物が新しく知ること

必要に応じて、持ち物・残数・時刻・距離などの台帳も使います。書き終えたら、本文と突き合わせて、状態にない物を使わせていないか、移動距離や時間がつながっているか、人物が知らないことを知っているように書いていないかを確認します。

### 執筆後の点検

本文を書いたあと、次の点検を順に回します。

1. lintスクリプトがあれば、記法・禁止語・段落長・文末の連続・記号量・語の反復を確認する
2. 一文ごとに分け、主述関係、修飾の掛かり先、省略された主語を確認する
3. 5行の進行メモや台帳と、持ち物・距離・時刻・視点人物の知識を照合する
4. 判断文の根拠・知識経路・射程を全件確認する
5. 台詞だけを抜き出して話者を追い、移動・受け渡し・時間経過を再現する

検出箇所があった場合は、修正するか、意図して維持する理由を残したときに点検完了とします。

## Before / After

AIに書かせた本文にありがちな一節:

> 森は静かだった。杉の葉ずれ。遠い沢の音。リオは歩いた。慎重に、進んだ。それはまさに、死と隣り合わせの探索だった。

このスキルを入れて書かせた一節:

> 杉の葉ずれと遠い沢の音のほかには、何も聞こえない森だった。リオは三歩に一度足を止めて、湿った土の匂いを確かめながら進む。その用心がどれほど要る森なのか、このときはまだ半分も分かっていなかった。

細切れの短文や空虚な総括を減らし、具体的な行動と、視点人物がその時点で持っている認識を残しています。

## 導入

`skills/fiction-prose-jp/` をClaude Codeの `~/.claude/skills/fiction-prose-jp/` またはCodexの `$HOME/.agents/skills/fiction-prose-jp/` にコピーします。同名のスキルが既にある場合は上書きされます。

### Windows（PowerShell）

```powershell
# Claude Code（既定値）
powershell -ExecutionPolicy Bypass -File .\install.ps1

# Codex
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Target codex

# Claude CodeとCodexの両方
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Target both
```

### macOS / Linux

```sh
# Claude Code（既定値）
sh install.sh

# Codex
sh install.sh codex

# Claude CodeとCodexの両方
sh install.sh both
```

## 使い方

小説の話・章・場面の執筆、または下書きの推敲・リライトを依頼すると、内容がスキルの `description` に一致した場合に読み込まれます。反映されない場合は、対象のホストを再起動してください。

Claude Codeで明示的に呼び出す例:

```text
/fiction-prose-jp 第3章の戦闘後の野営シーンを執筆してください。
視点人物はエリスです。彼女が知らない敵の正体について、地の文で断定しないでください。
```

Codexでは、次のようにスキル名を指定できます。

```text
$fiction-prose-jp 以下の原稿を推敲してください。
持ち物、移動距離、視点人物の知識経路を確認し、検出箇所と処置理由を残してください。
```

Claude Code以外のAIツールでも、`SKILL.md` は素のMarkdownとしてシステムプロンプトやカスタム指示に貼り付けて使えます。

## 注意点

- 作品固有の文体カルテ、用語集、キャラクターごとの口調規定がある場合は、それらを本スキルより優先してください。
- コメディ、不条理劇、意識の流れなど、意図的に論理や文体を崩す作品では、除外する規範を明示してください。
- スキルは未確認の飛躍を露出させるための道具です。作品の面白さ、設定の正しさ、最終的な表現の判断には人間のレビューが必要です。
